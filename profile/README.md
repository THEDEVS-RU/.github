# 👋 Привет

**THEDEVS.RU** — это IT-команда, создающая единую модульную экосистему для **монолитных приложений и микросервисов** на базе платформы **[Jmix](https://www.jmix.io/)**.

Мы разрабатываем **переиспользуемые модули**, которые делятся на два типа:

### 🔧 Промежуточные модули
Служат фундаментом для других модулей: предоставляют архитектуру, базовые сущности и общую логику.  
Например, наш core-модуль содержит архитектуру пользователей, телефонов, адресов — и от него наследуется большинство остальных модулей.

### 🚀 Конечные модули
Содержат прикладную бизнес-логику (например, интеграции с Telegram).  
Обычно подключаются напрямую к конечному продукту или микросервису.

На основе этих модулей собирается сам проект — с собственным дизайном, кастомной логикой и ролевой моделью.

---

## 🤲 Условия работы

1. **Система — наш общий продукт.**  
   Люди, участвующие в развитии экосистемы, могут в дальнейшем — по согласованию — использовать её в своих задачах и продуктах.

2. **Карьерная лестница.**  
   - Сначала можно брать только оценённые нами задачи с фиксированной стоимостью.  
   - Далее — переход на почасовую ставку и доступ к другой доске задач (с приоритетами, статусами, модулями). Видны только те задачи, к которым уже открыт доступ.  
   - Последний этап — оформление в штат. Даже при почасовой оплате ставка ежегодно растёт минимум на **10%**, без просьб и проверок навыков.

3. **Гибкий график.**  
   Забота о разработчике и качестве системы — выше отдельных проектов.  
   - Если у задачи нет сроков, её можно выполнять когда удобно (в разумных пределах).  
   - Важнее всего — **чистый, качественный, простой код**. Поэтому проекты стараются содержать JavaDoc (когда применимо) и быть простыми в сопровождении.

4. **Минимум митингов.**  
   Встречи только по необходимости — обсудить задачу, ошибку, решение или санкции. Обычно 1х1.  
   Полная удалёнка. Рай для интровертов.

## 🚀 Как начать

Для новичков доступна **публичная доска задач**:

1. Перейди на доску: https://github.com/orgs/THEDEVS-RU/projects/4  
2. Выбери задачу, которая понравится  
3. Напиши администратору:
   - чтобы получить назначение,
   - доступ к репозиторию,
   - согласовать условия.  
   📬 Контакты: https://github.com/THEDEVS-RU/.github/wiki/%F0%9F%93%AC-%D0%9A%D0%BE%D0%BD%D1%82%D0%B0%D0%BA%D1%82%D1%8B-%D0%B4%D0%BB%D1%8F-%D1%81%D0%B2%D1%8F%D0%B7%D0%B8

4. После назначения вы получите доступ к одному или нескольким репозиториям-модулям.

---

## 📘 После получения доступа

- Ознакомься с `README.md` в репозитории.
- Создай **Pull Request** в ветку **DEV** (master — только для прода).  
  В названии укажи номер задачи (например, «42»), а в описании — ссылку на задачу. Так MR автоматически свяжется с ней.
- В модулях задачи (Issues) служат трекингом времени:
  - **Почасовая ставка** — фиксируй отработанное время в комментариях и пушь изменения с номером задачи.  
  - **Фиксированная стоимость** — просто создай отчёт после завершения.

---

## ✅ Завершение задачи

1. Отправь администратору ссылку на Pull Request  
2. Дождись ревью и тестирования  
3. Получи расчёт и выплату

---

## 💡 Советы новичкам

- **Спрашивать обязательно.** Лучше уточнить, чем переделывать.  
- Пиши **чистый, простой, читаемый, переиспользуемый** код.  
- **Документируй** сложные решения и архитектурные особенности.  
- Не привязывай модули к конкретным проектам — они должны оставаться **универсальными**.
