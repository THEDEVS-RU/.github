# 🧱 Добро пожаловать на THEDEVS.RU

**THEDEVS.RU** — это модульная экосистема для разработки **монолитных приложений и микросервисов** на базе платформы **[Jmix](https://www.jmix.io/)**.

Мы создаём **переиспользуемые модули**, которые:
- могут подключаться к разным проектам одновременно;
- могут использоваться как независимые микросервисы.

---

## 🔧 Структура проектов

### 📌 Общая доска задач (GitHub Projects)

👉 [Перейти к доске](https://github.com/orgs/THEDEVS-RU/projects/4)

- Разработка новых модулей и микросервисов или просто задач
- Все задачи открыты для просмотра и выбора

### 📦 Репозитории модулей

- Каждый модуль имеет отдельный репозиторий
- Внутри находится `README`, документация и трекер задач (Issues)
- Доступ кода ограничен только активным участникам конкретного модуля не считая общих модулей

---

## 🚀 Как начать работу

1. Перейди на [доску задач](https://github.com/orgs/THEDEVS-RU/projects/4)
2. Выбери понравившуюся **неназначенную** задачу
3. Напиши администратору:
   - для получения назначения;
   - доступа к репозиторию;
   - согласования условий.
📬 [Контакты для связи](https://github.com/THEDEVS-RU/.github/wiki/%F0%9F%93%AC-%D0%9A%D0%BE%D0%BD%D1%82%D0%B0%D0%BA%D1%82%D1%8B-%D0%B4%D0%BB%D1%8F-%D1%81%D0%B2%D1%8F%D0%B7%D0%B8)

---

## 📘 После получения доступа

- Ознакомься с `README.md` внутри репозитория
- Начни работу над задачей:
  - **Почасовая ставка** — записывай время в комментариях
  - **Фиксированная стоимость** — просто создай отчёт по завершению
- Создай **Pull Request**, указав номер задачи в названии (например, `TD-42: Добавить сущность`)

---

## ✅ Завершение задачи

1. Отправь ссылку на Pull Request администратору
2. После ревью задачи
3. Расчёт вознаграждения

---

## 💡 Советы новичкам

- **Спрашивать — это нормально.** Лучше уточнить, чем переделывать
- Пиши **чистый, простой, читаемый и переиспользуемый код**
- **Документируй** сложные решения и архитектурные особенности
- Не привязывай модули к конкретным проектам — они должны быть **универсальными**
