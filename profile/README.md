# Привет!

**THEDEVS.RU** — Это аутсорс, основанный разработчиком, с единой, модульной экосистемой для разработки **монолитных приложений и микросервисов** на базе платформы **[Jmix](https://www.jmix.io/)**.

Мы создаём **переиспользуемые модули**, которые делятся на два типа:
- промежуточные модули, которые могут могут подключатся к другим модулям, для того чтобы предоставлять логику, или архитектуру (например от core модуля в котором заложена базовая архитектура пользователей, телефонов, адресов, налсдеуются практически все остальные модули)
- конечные модули, которые содержат бизнес логику, например интеграция с телеграммом, которые обычно подключаются к конечному продукту\микросервису.

А уже потом, из этих модулей составляется сам проект, внутри которого чащего всего содержится уникальный дизайн, кастомная логика или ролевка.

---
## 🚀 Как начать работу

- Первоначально, для новеньких, кто хочет присоединится к нашей команде, у нас есть публичная доска задач.

1. Перейди на [доску задач](https://github.com/orgs/THEDEVS-RU/projects/4)
2. Выбери понравившуюся задачу если они там есть
3. Напиши администратору:
   - для получения назначения;
   - доступа к репозиторию;
   - согласования условий.
📬 [Контакты для связи](https://github.com/THEDEVS-RU/.github/wiki/%F0%9F%93%AC-%D0%9A%D0%BE%D0%BD%D1%82%D0%B0%D0%BA%D1%82%D1%8B-%D0%B4%D0%BB%D1%8F-%D1%81%D0%B2%D1%8F%D0%B7%D0%B8)
4. Вы получите доступ к одному, или несколько репозиторию с модулем.

### 📦 Репозитории модулей
- Каждый модуль имеет отдельный репозиторий и служит своей конкретной задачи
- Чаще всего, внутри находится `README` который обязательно необходимо прочитать
- В каждом модуле "задачи"(Issues) так же являются трекингом вашего времени. Выполняя определенную задачу, в комментарии к этой задачи необходимо периодически, оставлять комментарии с вашими затраченными часами, а так же с кратким описанием того, что было сделано.

---

## 📘 После получения доступа

- Ознакомься с `README.md` внутри репозитория
- Начни работу над задачей:
  - **Почасовая ставка** — записывай время в комментариях, после списывания времени запуш то что сделал с соответствующим номером задачи, чтобы можно было посмотреть что было сделано за этот период
  - **Фиксированная стоимость** — просто создай отчёт по завершению
- Создай **Pull Request** в ветку **DEV**(master используется только для прода), указав номер задачи в названии (например если задача с номером 42, то МР тоже просто должен содержать эту цифру.), а в описании оставить ссылку на задачу, тогда ваш ПР будет связан с сзадачей, и ваши коммиты так же отобразятся и в задаче.

---

## ✅ Завершение задачи

1. Отправь ссылку на Pull Request администратору
2. После ревью задачи и тестирования
3. Расчёт вознаграждения

## 💡 Советы новичкам

- **Спрашивать — это обязательно.** Лучше уточнить, чем переделывать
- Пиши **чистый, простой, читаемый и переиспользуемый код**
- **Документируй** сложные решения и архитектурные особенности
- Не привязывай модули к конкретным проектам — они должны быть **универсальными**
